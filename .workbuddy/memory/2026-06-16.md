## 紧急修复：代码版本回退恢复

**问题**：package.json 版本从 1.5.79 回退到 1.5.17，用户之前的多版本修改全部丢失。

**根因**：`origin/main` 被 reset 到旧版本（commit 15519cc9），导致 v1.5.28~v1.5.79 共 28 个提交脱离 main 分支。虽然 tag 还在本地，但代码不在 HEAD 上。

**恢复操作**：
1. 创建备份分支 `backup/1.5.17-current` 保留当前 HEAD
2. `git reset --hard v1.5.79` 恢复代码到 v1.5.79 tag
3. `git push --force origin main` 覆盖远程

**结果**：代码已恢复到 v1.5.79 状态，origin/main 已同步。备份分支 `backup/1.5.17-current` 保留以备需要时查看。
