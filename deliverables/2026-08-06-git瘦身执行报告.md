# Git 仓库瘦身执行报告

> 执行时间：2026-08-06｜不可逆操作，已获用户授权（"都执行"）

## 背景
仓库 `.git` 体积膨胀至 **732M**（pack 678 MiB），根因是构建产物被误提交进历史：
- `server_dist/`：`index.mjs`(98M) + `index.cjs`(92M) + 历史多次重建的 cjs 多版本约 350MB+
- `coverage/`、`report/`（生成物）

此前 git 仓库实测 634MiB 的口径被低估（旧记 144MB 完全失准），本次实测基线 732M。

## 执行步骤
1. **工作树全干净**：主仓 + 双子模块（StaffDeck-main / openclaw）`git status -s` 均 0 改动。
2. **filter-repo 重写历史**：
   ```
   /Users/chouray/.workbuddy/binaries/python/envs/default/bin/git-filter-repo \
     --path server_dist/ --path coverage/ --path report/ --invert-paths --force
   ```
   - 使用隔离 venv（default env，py3.14）里的 `git-filter-repo`
   - `--force` 是因仓库非 fresh clone（filter-repo 默认保护机制拒绝，需显式跳过）；剥离目标不变
   - 重写 757 commits / 37,732 objects，耗时 ~53s
3. **压缩**：`git gc --aggressive`
4. **子模块完整性校验**：`git ls-tree HEAD` 确认 `StaffDeck-main`(0ef1791) / `openclaw`(45221ca5) 仍为 `160000` gitlink —— **未被误剥**（剥离路径与子模块无关）。
5. **重连远程**：filter-repo 默认移除 `origin`，重新 `git remote add origin git@github.com:chouraycn/cross-wms.git`。
6. **强推**：`git push --force --all`（所有分支 forced update）+ `git push --force --tags`（416 个 tags 全部 forced update）。
