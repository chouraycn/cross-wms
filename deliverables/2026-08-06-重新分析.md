## 2. 新发现：`components/staff/` 不是死代码，而是"被误命名的共享 UI 库"

前报把 `src/components/staff/` 描述为"5 例外页的布局外壳"。本次核查发现它**被全应用复用**：

- **核心引线**：`i18n`（被 Pairing / Transfer / Dashboard / Reports / Inventory / Partners / Channels / Wms* / InTransit / NotFound / ChatContext / TopBarChatInput 等 ≥14 处引用）、`StaffDeckPortal`、`StaffLayout`、`auth/api/types/ui` barrel、`BrandLogo`、`DataTable`、`Paginator`。
- **跨页复用**：Grep 显示 `NavList.tsx`、`SettingsPopover.tsx`、`ContextEngineRegistryPage.tsx`、`SkillWorkshopPage.tsx` 也引用了本目录组件（StatCard / DetailField / CodeBlock / EmployeeCard 等）。

→ 结论：`components/staff/` 实为**通用组件工具箱**，legacy 页面删除后它依然 alive。问题是**目录名 `staff` 已名不副实**，建议后续重命名为 `components/ui-kit/` 或 `components/shared/`（低优先级整洁项，非阻塞）。

> 精确"哪些是真死代码"需 Bash 跑 `tsc --noEmit` 未用导出检查或精确反向引用，列为 §6 待补核验。
